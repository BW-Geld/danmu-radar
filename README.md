# 弹幕雷达

工具在本地跑，可采集斗鱼直播间弹幕。

弹幕库数据存在电脑本地。

用的是斗鱼公开的弹幕接口，不需要登录、不需要 API key、不往任何服务器上传东西。

## 能做什么

- **实时弹幕**：滚动显示房间内实时弹幕，统计弹幕潮
- **关键词检索**：利用关键词检索有关弹幕，按被 +1 次数排行，可检索上下文关联弹幕，可选择关键词拓展
- **用户**：通过昵称或 uid 检索弹幕库中的用户，可看其房间分布、活跃时段、高频发言、历史发言
- **排行榜**：展示发言量前 100 的用户、被 +1 次数最多前 100 名的弹幕，可以选日期
- **时间线**：展示房间所有ai看点，含24 小时弹幕热力图，框出范围就展示这段时间的高频弹幕
- **收藏夹 / 关注**：收藏弹幕、关注某个观众，可以跨窗口同步
- **录播导入**：输入录播链接补全弹幕库

弹幕库初始为空，可以导入弹幕库文件补全自身弹幕库，也可以导出文件与他人分享。

## 怎么使用

1. 解压到任意位置，双击 `弹幕雷达启动程序.vbs`
2. 等一两秒，会弹出独立窗口；没弹就手动打开 http://127.0.0.1:7788
3. 在左侧输入房间号（比如 `6657`）点「添加」，弹幕开始实时入库

想要桌面图标：双击 `在桌面创建快捷方式.vbs`。

## 技术细节

- **零第三方依赖**：完全基于 Node.js 原生模块开发，无任何 `npm install`
- **底层协议直连**：基于 TLS 与 WebSocket 握手，原生解析斗鱼 STT 二进制协议
- **本地化存储**：基于内置 `node:sqlite`，WAL 模式批量落库，支持断线重连与采集缺口记录
